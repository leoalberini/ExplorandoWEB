Galería de tecnologías web

Conoce las tres principales tecnologías utilizadas para crear y desarrollar páginas web modernas.

HTML5

Es el lenguaje de marcado utilizado para estructurar el contenido de las páginas web.

CSS3

Permite modificar los colores, fuentes, tamaños y apariencia visual de una página web.

JavaScript

Permite agregar interactividad, animaciones y comportamiento dinámico a los sitios web.
